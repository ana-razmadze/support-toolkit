# Knowledge Base (BrightCart Help Center)

Articles for customers of a pretend online shop. Each one is short, uses simple words, and has numbered steps.

**Rules I follow when I write an article:**
- One problem per article
- Title = the question the customer would type
- Steps are numbered, one action each
- Say what the customer should see after each important step
- End with "Still need help?" so nobody gets stuck
