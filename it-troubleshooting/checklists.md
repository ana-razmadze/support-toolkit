# IT Troubleshooting Checklists

Step-by-step checklists for common problems. Always go from **easy to hard**, and test after each step.

## First, ask these 5 questions

1. What exactly is not working? What do you see on the screen?
2. When did it start? Did anything change before it (update, new program, new password)?
3. Does it happen for everyone, or only for you?
4. Does it happen all the time, or sometimes?
5. Can you send a screenshot?

Then: **write down what you tried.** If you have to escalate, the next person will thank you.

---

## 1. Computer is slow or freezing

1. Save your work. Restart the computer. (Yes, this fixes many problems.)
2. Close programs you do not use. Open Task Manager (Ctrl + Shift + Esc) and look at what uses the most CPU or memory.
3. Check free disk space. Less than 10% free can make the computer slow.
4. Check for system updates and install them.
5. Run a virus scan.
6. Check startup programs and turn off the ones you do not need.
7. Still slow? Escalate with the Task Manager screenshot.

## 2. No internet / WiFi problem

1. Is WiFi turned on? Is airplane mode off?
2. Can other devices connect to the same WiFi? If no, the problem is the router.
3. Turn WiFi off and on again.
4. Restart the router: unplug for 30 seconds, plug back in, wait 2 minutes.
5. Forget the network and connect again with the password.
6. Try a cable connection if possible.
7. Still no internet? Call the internet provider and give them the results from step 2 and 4.

## 3. Cannot log in

1. Check Caps Lock and the keyboard language.
2. Try the password reset link.
3. Check if the account is locked (too many wrong tries). Wait 15 minutes or ask an admin to unlock it.
4. Try another browser or a private window.
5. Clear browser cache and cookies.
6. If there is two-factor login, check the phone time is correct.
7. Escalate to the admin team if nothing works. Include username and exact error message.

## 4. Printer does not print

1. Is the printer on? Any red light or error on the display?
2. Paper, ink or toner OK? Paper jam?
3. Is it the right printer selected on the computer?
4. Cancel all print jobs in the queue and try again.
5. Restart the printer and the computer.
6. Check the cable or WiFi connection.
7. Reinstall the printer driver.

## 5. Email problems

**Cannot send or receive:**
1. Check internet first.
2. Check if the mailbox is full.
3. Check the Spam / Junk folder.
4. Try the webmail in a browser. If it works there, the problem is in the email app.
5. Remove and add the account again in the app.

**Email did not arrive for someone else:**
1. Check the email address for spelling mistakes.
2. Check the Sent folder and look for a "bounce back" error.
3. Ask them to check Spam.

## 6. VPN does not connect

1. Check normal internet works.
2. Check username and password. Check the VPN app is updated.
3. Disconnect, close the app, open it, connect again.
4. Try a different VPN server.
5. Restart the computer.
6. If it fails for many people, escalate right away. It may be a server problem.

## 7. Program crashes or will not open

1. Restart the program. Then restart the computer.
2. Check for updates for the program.
3. Check if the problem is new after a Windows or Mac update.
4. Uninstall and install again.
5. Look at the error message. Search for the exact words. Check the company help page.
6. Escalate with the error message and the steps to repeat the problem.

---

## Good habits

- Be kind. Many people feel stressed or "not good with computers". Never make them feel silly.
- Use simple words. Say "restart" not "reboot the system".
- Ask permission before you change anything.
- Never ask for a password. Never.
- At the end, ask: "Is it working now?" and then write what fixed it.
